Bab 01

Print

Menampilkan output ke layar

print() adalah fungsi paling fundamental di Python. Hampir setiap program menggunakannya untuk menampilkan teks, angka, hasil perhitungan, atau isi variabel ke layar terminal.

Sintaks Dasar
python
print(nilai)                  # cetak satu nilai
print(nilai1, nilai2, ...)    # cetak beberapa nilai
print(f"teks {variabel}")     # f-string (cara modern)
Contoh 1 — Print Sederhana
contoh_1.py
# Menampilkan teks
print("Halo, Dunia!")
print("Selamat belajar Python")

# Menampilkan angka
print(100)
print(3.14)

# Menampilkan beberapa nilai sekaligus
print("Nama:", "Budi", "Usia:", 20)
Output
Halo, Dunia! Selamat belajar Python 100 3.14 Nama: Budi Usia: 20
Contoh 2 — Parameter sep dan end

Parameter sep mengatur pemisah antar nilai (default: spasi). Parameter end mengatur karakter di akhir baris (default: baris baru \n).

contoh_2.py
# sep: ubah pemisah antar nilai
print("A", "B", "C", sep="-")
print(1, 2, 3, sep=" | ")

# end: cetak tanpa garis baru
print("Loading", end="")
print("...")

# Kombinasi
print("Python", "is", "fun", sep="_", end="!\n")
Output
A-B-C 1 | 2 | 3 Loading... Python_is_fun!
Contoh 3 — F-String (Format String)

F-string adalah cara paling modern dan elegan untuk memasukkan variabel ke dalam teks. Tambahkan huruf f sebelum tanda kutip, lalu tulis nama variabel dalam kurung kurawal { }.

contoh_3.py
nama  = "Sari"
usia  = 21
kota  = "Jakarta"

# Masukkan variabel langsung ke dalam teks
print(f"Nama saya {nama}")
print(f"Saya berusia {usia} tahun")
print(f"Tinggal di {kota}")

# F-string bisa juga berisi ekspresi
print(f"Tahun depan saya berusia {usia + 1} tahun")
print(f"3 x 4 = {3 * 4}")
Output
Nama saya Sari Saya berusia 21 tahun Tinggal di Jakarta Tahun depan saya berusia 22 tahun 3 x 4 = 12
💡
Tips

Gunakan f-string untuk kode yang lebih bersih dan mudah dibaca. f"Halo {nama}" jauh lebih elegan daripada "Halo " + nama.

Bab 02

Input

Menerima data yang diketik pengguna

input() adalah fungsi untuk menerima data dari pengguna melalui keyboard. Program akan berhenti sejenak dan menunggu pengguna mengetik sesuatu, lalu menekan Enter. Penting: hasil dari input() selalu bertipe string.

⚠️
Perhatian Penting

input() selalu menghasilkan tipe str (string). Jika ingin menggunakannya untuk perhitungan, wajib dikonversi terlebih dahulu:
int(input(...)) → bilangan bulat  |  float(input(...)) → bilangan desimal

Contoh 1 — Input Teks
contoh_4.py
nama = input("Masukkan nama Anda: ")
print(f"Halo, {nama}! Selamat datang di Python.")
Output
Masukkan nama Anda: Budi Halo, Budi! Selamat datang di Python.
Contoh 2 — Input Angka dengan Konversi
contoh_5.py
# Konversi ke int agar bisa dihitung
umur = int(input("Berapa umur Anda? "))
print(f"Umur Anda: {umur} tahun")
print(f"10 tahun lagi: {umur + 10} tahun")

# Konversi ke float untuk angka desimal
tinggi = float(input("Tinggi badan (meter): "))
berat  = float(input("Berat badan (kg): "))
print(f"Data: tinggi {tinggi}m, berat {berat}kg")
Output
Berapa umur Anda? 20 Umur Anda: 20 tahun 10 tahun lagi: 30 tahun Tinggi badan (meter): 1.72 Berat badan (kg): 65 Data: tinggi 1.72m, berat 65.0kg
Bab 03

Tipe Data

Jenis-jenis data yang dikenali Python

Python secara otomatis menentukan tipe data sebuah variabel saat nilainya ditetapkan (dynamic typing). Memahami tipe data penting agar tidak terjadi error saat melakukan operasi.

Tabel Tipe Data Utama
TipeContoh NilaiKeterangan
int1, -5, 100, 0Bilangan bulat, tanpa titik desimal
float3.14, -0.5, 2.0Bilangan dengan titik desimal
str"Halo", 'Python'Teks / kumpulan karakter
boolTrue, FalseNilai logika benar atau salah
list[1, 2, 3]Kumpulan data terurut, bisa diubah
dict{"nama": "Budi"}Pasangan kunci–nilai
NoneTypeNoneTidak ada nilai (seperti null)
Contoh Setiap Tipe Data
tipe_data.py
# Integer
umur    = 25
siswa   = 30

# Float
tinggi  = 1.75
pi      = 3.14159

# String — kutip tunggal atau ganda sama saja
nama    = "Budi Santoso"
kota    = 'Jakarta'

# Boolean
sudah_login  = True
is_admin     = False

# Cek tipe dengan type()
print(type(umur))    # <class 'int'>
print(type(tinggi)) # <class 'float'>
print(type(nama))   # <class 'str'>
print(type(sudah_login)) # <class 'bool'>
Operasi pada String
string_ops.py
nama = "Budi Santoso"

print(nama.upper())        # BUDI SANTOSO
print(nama.lower())        # budi santoso
print(len(nama))           # 12 (jumlah karakter)
print(nama[0])             # B  (indeks pertama)
print(nama + " Jr.")        # Budi Santoso Jr.
print("Python" * 3)        # PythonPythonPython
Konversi Tipe Data (Type Casting)
type_casting.py
# String → int
angka_str = "42"
angka_int = int(angka_str)
print(angka_int + 8)    # 50

# int → float
print(float(5))         # 5.0

# int → string (untuk penggabungan teks)
nilai = 100
print("Nilai: " + str(nilai))   # Nilai: 100
Bab 04

Variabel

Menamai dan menyimpan data di memori

Variabel adalah nama yang kita berikan untuk menyimpan data di memori komputer. Di Python, tidak perlu mendeklarasikan tipe variabel — Python otomatis menentukan tipenya dari nilai yang diberikan.

Aturan Penamaan Variabel
  • Hanya boleh mengandung huruf, angka, dan underscore (_)
  • Tidak boleh dimulai dengan angka
  • Tidak boleh menggunakan kata kunci Python: if, for, while, class, dll.
  • Bersifat case-sensitive: nama dan Nama adalah variabel berbeda
  • Gunakan snake_case untuk nama yang panjang: nama_lengkap, jumlah_siswa
variabel.py
# ✅ Nama variabel yang benar
nama         = "Andi"
usia_user    = 25
nilai1       = 90
_catatan     = "private"

# ❌ Nama variabel yang SALAH (akan error!)
# 1nama = "error"     → tidak boleh dimulai angka
# if = 10             → kata kunci Python
# nama-lengkap = ...  → tanda minus tidak boleh
Multiple Assignment dan Swap
multi_assign.py
# Assign banyak variabel dalam satu baris
a, b, c = 1, 2, 3
print(a, b, c)       # 1 2 3

# Nilai sama ke banyak variabel
x = y = z = 0
print(x, y, z)       # 0 0 0

# Swap dua variabel — Python sangat ringkas!
a = 10
b = 20
a, b = b, a
print(a, b)          # 20 10

Operator

Melakukan operasi pada nilai dan variabel

Operator adalah simbol yang digunakan untuk melakukan operasi — dari perhitungan matematika hingga perbandingan nilai dan logika kondisional.

Contoh Penggunaan Operator
operator.py
a, b = 15, 4

# Aritmatika
print(f"{a} + {b} = {a + b}")      # 19
print(f"{a} // {b} = {a // b}")    # 3
print(f"{a} % {b} = {a % b}")      # 3
print(f"2 ** 10 = {2 ** 10}")       # 1024

# Assignment gabungan
x = 10
x += 5     # x = x + 5  →  15
x *= 2     # x = x * 2  →  30
print(x)   # 30

# Operator logika
usia      = 20
punya_ktp = True
bisa_vote = usia >= 17 and punya_ktp
print(f"Bisa voting: {bisa_vote}")   # True
Bab 06

Kondisional

Membuat program yang bisa mengambil keputusan

Pernyataan kondisional memungkinkan program berjalan secara berbeda tergantung situasi: "Jika kondisi ini terpenuhi, lakukan ini — jika tidak, lakukan yang lain."

Struktur if / elif / else
struktur.py
if kondisi1:
    # dijalankan jika kondisi1 bernilai True
elif kondisi2:
    # dijalankan jika kondisi2 bernilai True
elif kondisi3:
    # dijalankan jika kondisi3 bernilai True
else:
    # dijalankan jika semua kondisi di atas False
📌
Indentasi Wajib!

Python menggunakan indentasi (4 spasi atau 1 tab) untuk menandai blok kode di dalam kondisi. Tanpa indentasi yang benar, program akan menghasilkan IndentationError.

Contoh 1 — Cek Nilai Ujian
nilai_ujian.py
nilai = int(input("Masukkan nilai ujian (0–100): "))

if nilai >= 90:
    print("Grade: A — Sangat Baik! 🌟")
elif nilai >= 80:
    print("Grade: B — Baik 👍")
elif nilai >= 70:
    print("Grade: C — Cukup")
elif nilai >= 60:
    print("Grade: D — Kurang")
else:
    print("Grade: E — Tidak Lulus ❌")
Output (nilai = 85)
Masukkan nilai ujian (0–100): 85 Grade: B — Baik 👍
Contoh 2 — Ganjil atau Genap
ganjil_genap.py
angka = int(input("Masukkan sebuah angka: "))

if angka % 2 == 0:
    print(f"{angka} adalah bilangan GENAP")
else:
    print(f"{angka} adalah bilangan GANJIL")
Contoh 3 — if Bersarang (Nested if)
cek_voting.py
usia      = int(input("Masukkan usia: "))
punya_ktp = input("Punya KTP? (ya/tidak): ")

if usia >= 17:
    if punya_ktp == "ya":
        print("✅ Anda memenuhi syarat untuk memilih")
    else:
        print("⚠️  Silakan buat KTP terlebih dahulu")
else:
    sisa = 17 - usia
    print(f"❌ Belum cukup umur, kurang {sisa} tahun lagi")
Contoh 4 — Cek Cuaca dengan and / or
cek_cuaca.py
suhu = float(input("Suhu hari ini (°C): "))

if suhu >= 35:
    print("🔥 Sangat panas! Minum air yang banyak")
elif suhu >= 28 and suhu < 35:
    print("☀️  Panas biasa, tetap jaga hidrasi")
elif suhu >= 20 and suhu < 28:
    print("🌤  Cuaca nyaman untuk beraktivitas")
elif suhu >= 15 and suhu < 20:
    print("🌥  Agak dingin, pakai jaket tipis")
else:
    print("🥶 Sangat dingin! Kenakan jaket tebal")
Output (suhu = 31)
Suhu hari ini (°C): 31 ☀️ Panas biasa, tetap jaga hidrasi
★ Mini Project — Materi 1

Kalkulator BMI Interaktif

Program yang menggabungkan semua konsep Materi 1: print, input, tipe data, variabel, operator, dan kondisional dalam satu program yang benar-benar berguna.

print() input() float / int variabel operator ** if / elif / else
Rumus BMI
BMI = Berat (kg) ÷ Tinggi (m)²
Kategori BMI
BMI < 18.5
😟 Kurus (Underweight)
Perbanyak asupan kalori dan protein. Konsultasi ke dokter gizi.
18.5 – 24.9
😊 Normal (Ideal)
Pertahankan gaya hidup sehat. Olahraga rutin dan makan bergizi.
25.0 – 29.9
😐 Gemuk (Overweight)
Kurangi makanan tinggi kalori. Perbanyak aktivitas fisik harian.
BMI ≥ 30.0
😰 Obesitas
Sangat disarankan konsultasi dengan dokter untuk program diet aman.
Kode Program Lengkap
kalkulator_bmi.py
# ================================================
#      KALKULATOR BMI — Mini Project Python        
#         Materi 1: Dasar Python                   
# ================================================

# ── HEADER PROGRAM ──────────────────────────────
print("=" * 45)
print("   🐍 KALKULATOR BMI — Python Materi 1")
print("=" * 45)
print()

# ── INPUT DATA PENGGUNA ──────────────────────────
nama   = input("Nama Anda          : ")
berat  = float(input("Berat badan (kg)   : "))
tinggi = float(input("Tinggi badan (cm)  : "))

# ── KONVERSI & HITUNG BMI ────────────────────────
tinggi_m  = tinggi / 100               # cm → meter
bmi       = berat / (tinggi_m ** 2)     # rumus BMI
bmi_bulat = round(bmi, 1)               # bulatkan 1 desimal

# ── TENTUKAN KATEGORI ────────────────────────────
if bmi < 18.5:
    kategori = "Kurus (Underweight)"
    saran    = "Perbanyak asupan kalori & protein"
    emoji    = "😟"
elif bmi < 25.0:
    kategori = "Normal (Ideal)"
    saran    = "Pertahankan gaya hidup sehat!"
    emoji    = "😊"
elif bmi < 30.0:
    kategori = "Gemuk (Overweight)"
    saran    = "Kurangi kalori & perbanyak olahraga"
    emoji    = "😐"
else:
    kategori = "Obesitas"
    saran    = "Konsultasikan ke dokter segera"
    emoji    = "😰"

# ── TAMPILKAN HASIL ──────────────────────────────
print()
print("=" * 45)
print("        HASIL ANALISIS BMI")
print("=" * 45)
print(f"Nama          : {nama}")
print(f"Berat         : {berat} kg")
print(f"Tinggi        : {tinggi} cm ({tinggi_m} m)")
print("-" * 45)
print(f"Nilai BMI     : {bmi_bulat}")
print(f"Kategori      : {emoji} {kategori}")
print("-" * 45)
print(f"💡 Saran      : {saran}")
print("=" * 45)
